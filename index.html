THE LODGE SMP

A survival server that still feels like Minecraft.

The Lodge is built around a simple idea: add cool things without forcing every player to learn a completely different game.

Explore, build, automate, decorate, trade, and make your own place in the world. The modpack adds depth while keeping the familiar Minecraft survival loop at the center.

QUESTIONS

Frequently asked.

What Minecraft version is The Lodge on?

Set your current server version in site-config.js. The starter config is prepared for the 1.21.1 / NeoForge setup you have been working toward.

Can Bedrock players join?

Not yet, The site labels the server as Java + Bedrock so visitors know crossplay is part of the plan.

Where do I get the modpack?

Tap the Modrinth button.

How do I get help?

Join the Discord and use the support/help channel.
