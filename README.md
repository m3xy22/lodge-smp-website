# Lodge website assets

Put your real Lodge screenshots in `assets/gallery/` using these names:

- lodge-01.jpg
- lodge-02.jpg
- lodge-03.jpg
- lodge-04.jpg

You can use PNGs too — just update the filenames in `site-config.js`.

The current website intentionally uses CSS artwork as placeholders so it works immediately without needing copyrighted/third-party images.
